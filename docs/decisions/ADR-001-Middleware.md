# ADR-001: Middleware Structure

Status: **Accepted**

## Context

The number of files for the middleware made importing those functions impractical

## Decision

I chose to condense the seperate files into one file simply named middleware.js

## Consequences

The advantages are ease of use and condensability. One disadvantage is it may become more difficult to update but not to a very detrimental degree 

## Alternatives Considered

I considered trying to further condense it however the possible consequences became too negative
